2. Arquitectura de Doble API y Procesamiento de Datos

La presente aplicación opera funcionalmente mediante una arquitectura de integración dual basada en dos APIs (Interfaces de Programación de Aplicaciones) independientes y externas:

  • API Meteorológica: Encargada de la extracción asíncrona de datos climatológicos, variables atmosféricas e índices térmicos en tiempo real.
  • API de Inteligencia Artificial: Motor de procesamiento de lenguaje natural y computación avanzada que da soporte analítico al chat integrado en la plataforma.

Debido a la dependencia de estas infraestructuras de terceros (nodos cuánticos y servidores externos en la nube), el servicio global se proporciona bajo la premisa "tal cual" (as is). El usuario acepta explícitamente que la disponibilidad simultánea de ambas APIs puede verse comprometida por saturación de red, límites de cuota (rate-limiting), latencias en cola o mantenimientos técnicos ajenos al titular de este sitio web, provocando la interrupción temporal del flujo de datos en la interfaz.

3. Condiciones Operativas del Chat de Manolito (IA)

El módulo conversacional integrado es operado de forma dinámica por la segunda API del sistema. Para asegurar un uso responsable y garantizar la privacidad, se estipulan las siguientes condiciones técnicas:

  • Ausencia de Persistencia: El modelo opera bajo un flujo de memoria estrictamente volátil. El sistema no guarda registros en bases de datos, no crea perfiles de usuario, ni almacena el historial de las interacciones una vez finalizada la sesión (cierre de pestaña o recarga del DOM).
  • Procesamiento Externo: Las consultas enviadas al chat son canalizadas de forma anonimizada a través de la API de IA correspondiente. Al no existir bases de datos propias, se garantiza un paradigma de "privacidad por diseño" y cero contacto con información personal identificable.
  • Limitación de Fiabilidad (Alucinaciones): La IA es una interfaz probabilística diseñada para interpretar datos climáticos del proyecto. Las respuestas generadas no constituyen asesoramiento profesional, científico o vinculante. El modelo puede incurrir en errores de interpretación o generar respuestas inexactas inherentes a la tecnología LLM actual.
