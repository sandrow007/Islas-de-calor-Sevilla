Visión General: El "Caballo de Troya" Climático
Manolit∞ no es solo un panel de datos; es una infraestructura digital diseñada para transformar el futuro de Sevilla
. Bajo una apariencia de aplicación web ligera y rápida, se esconde una arquitectura de software dual hipercompleja capaz de gestionar datos climáticos en tiempo real y proyectarlos hacia la computación cuántica
.
 Dualidad Funcional
El sistema opera bajo dos paradigmas diseñados para la resiliencia urbana:
1. Modo Ciudadano (Supervivencia Inmediata)
Diseñado para la población general, utiliza un sistema de semáforo de riesgo intuitivo
:
🟢 Riesgo Bajo: Estabilidad climática.
🟡 Riesgo Medio: Advertencia y precaución.
🔴 Riesgo Alto: Alerta roja urgente por calor extremo.
Objetivo: Permitir decisiones rápidas ante olas de calor sin necesidad de descifrar fórmulas matemáticas
.
2. Modo Científico (Laboratorio Virtual)
Un entorno avanzado para investigadores que revela módulos de circuitos cuánticos y barras de probabilidad
:
Variables de Entrada: Procesa 6 pilares físicos: Temperatura (aire y superficie), Humedad, Viento y Radiación Solar (entrante y neta)
.
Esfera de Bloch: Visualización geométrica en 3D que mapea el riesgo climático en coordenadas cuánticas
.
   Innovación: Real Quantum Engine
El núcleo del proyecto es un motor de simulación que prepara a Sevilla para la supremacía cuántica
:
Simulación de Qubits: Traduce datos meteorológicos a propiedades angulares (radianes) para simular estados de superposición
.
Compuesto QCI (Qubit 6): Una métrica definitiva que destila el caos atmosférico en un solo valor de precisión máxima para alertas institucionales
.
Visión de Futuro: La lógica está construida bajo parámetros cuánticos puros. Cuando el hardware cuántico despegue, el modelo solo tendrá que conectarse, no reinventarse
.
 Despliegue y Tecnología
Stack: HTML5, CSS3 avanzado (animaciones de latido asíncronas), JavaScript (Three.js)
.
Infraestructura: Despliegue continuo (CD) mediante Netlify e integración con Git
.
Robustez SPA: Incluye configuración de redirecciones universales (_redirects) para garantizar una navegación sin errores 404:
   Instalación y Uso
Clona el repositorio.
Asegúrate de que los archivos index.html, style.css, script.js y _redirects estén en la raíz
.
Despliega en Netlify conectando tu rama de GitHub.
